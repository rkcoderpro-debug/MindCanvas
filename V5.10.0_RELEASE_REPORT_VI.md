# MindCanvas v5.10.0 — báo cáo triển khai, kiểm chứng và blocker

## Trạng thái

Mã v5.10.0 đã được triển khai và vượt các gate tự động/unit, typecheck,
production build, server health và fixture render. Đây chưa phải production
release đã nghiệm thu toàn bộ: browser E2E/screenshot UI không chạy được trong
container hiện tại vì không có Chrome/Firefox executable; Word desktop không có;
layout phân trang thật và một số OOXML nâng cao còn là blocker được ghi rõ bên
dưới. Không có cloud storage, public upload, credential mới hay dịch vụ trả phí.

## Thay đổi chính

### DOCX editor thực dụng

- Structured model tại `apps/web/src/lib/docxModel.ts`; DOM chỉ là bề mặt tương
  tác, không phải nguồn dữ liệu duy nhất.
- Import có giới hạn 40 MB, kiểm tra ZIP/document.xml, đọc styles/numbering/
  relationships/media/section/header/footer và báo warning thân thiện cho style
  tùy chỉnh, ảnh nổi, row merge, OMML hoặc block OOXML chưa hỗ trợ.
- Export tạo OOXML package với document/styles/numbering/relationships,
  hyperlinks, media, page settings, header/footer và PAGE field; file nguồn
  không bị ghi đè.
- Ribbon Home/Insert/Layout/View, rename, trạng thái lưu, undo/redo, Lưu, Lưu
  bản sao, Xuất DOCX, fullscreen, ruler, page/continuous view, A4/Letter,
  portrait/landscape, lề cm, zoom và status bar.
- Định dạng: Normal/Title/Subtitle/Heading 1–6/Quote, font/cỡ 0.5 pt,
  bold/italic/underline/strike/superscript/subscript, màu/highlight, align,
  list, indent, find/replace, symbol, hyperlink và copy/clear format.
- Bảng: chèn, thêm/xóa hàng/cột, gộp/tách ô trong phạm vi đã cam kết, header,
  màu nền/căn ô và xóa có xác nhận. Ảnh: chèn/paste, alt, resize giữ tỷ lệ,
  căn inline, thay/xóa; media được ghi vào `word/media` và relationship hợp lệ.
- Header/footer chỉnh sửa trong giấy; export footer có PAGE field. Ngắt trang
  chủ động và section/page settings được giữ trong model.

### Lưu và phục hồi

`docxDraftStore.ts` lưu model draft trong IndexedDB `mindcanvas-docx-drafts-v1`
theo owner/document ID/base revision. Draft stale không tự ghi đè bản mới; UI
cho khôi phục hoặc mở bản hiện tại. Transaction lỗi giữ nguyên nội dung editor
và trạng thái “Lưu thất bại”. Lần Lưu đầu từ file nhập tạo `${name} — bản sửa.docx`;
lần sau cập nhật cùng document ID; Lưu bản sao tạo ID mới. Bản gốc vẫn ở
repository tài liệu cục bộ.

### Tích hợp tool và guide

`DocumentToolsPage` có tab PDF/DOCX, tìm trong thư viện và tạo DOCX trắng.
Guide dùng action typed theo document ID + guide session ID; bước DOCX chờ
`docx:focus`, `docx:text`, `docx:selection`, `docx:format`, `docx:table`,
`docx:save`, `docx:export`. `DocumentViewer` chỉ request PDF guide khi kind là
PDF và dedicated/ready path đúng.

### Dựng lại UI tab Công cụ

- Tab Công cụ chuyển sang khung làm việc hai vùng: header gọn chứa chuyển PDF/
  DOCX và tải tài liệu; thư viện bên trái; viewer/editor bên phải.
- Tìm kiếm và cuộn danh sách tài liệu được cô lập trong thư viện; thư viện có
  thể thu gọn để dành thêm chiều rộng cho trang giấy.
- DOCX ribbon có bố cục nhóm ổn định, nút thu gọn thật và menu thao tác bổ sung
  cho màn hình hẹp. Các lệnh tài liệu và event guide không đổi.
- Đây là thay đổi giao diện; chưa tuyên bố đã có phân trang editable thật.

## Nguyên nhân và cách vá lỗi guide PDF/DOCX

Bản lỗi dùng selector dòng tài liệu chung và event mở không có `kind`/document
ID, nên DOCX đứng trước PDF có thể làm PDF guide tiến sai. Đây là lỗi định tuyến
target/event, chưa có bằng chứng để gọi là đọc nhầm bytes.

Đã vá bằng `data-document-kind`, `data-document-id`, `tools:pdf-open`,
`viewer-ready` sau khi PDF.js resolve thành công, `viewerSessionId` và
`guideSessionId`. Listener/timer cleanup khi close/route/unmount. Guide DOCX
không chờ event `docx:open` đã xảy ra trước khi overlay tới bước đó; nó yêu cầu
user focus vùng `.docx-editable`, rồi mới chờ text/selection/format/table/save/
export. Regression DOCX-first/PDF và stale session đều pass.

## Môi trường và blocker kích hoạt

- Node `v24.19.0`, npm `11.9.0`, TypeScript/Vite/Vitest trong lockfile: đã có.
- `soffice`/LibreOfficeDev và Poppler: đã có, dùng cho fixture render.
- Browser thật: **thiếu**. Playwright runner có trong runtime nhưng browser
  executable/cache không có; cần cài/đưa vào CI Chrome hoặc Firefox, sau đó
  chạy dev server ở origin mà browser truy cập được và chụp guide/editor.
- Biến server hiện tại trong runtime có giá trị URL không hợp lệ; smoke phải
  override `WEB_ORIGIN` và `EXPERIENTIAL_LABS_BASE_URL` bằng URL đầy đủ như
  `http://localhost:5173`. Không ghi credential vào repo.
- Word desktop: thiếu; cần máy Windows/Office hoặc CI được cấp phép để đóng
  cổng Word round-trip. Không coi LibreOffice là bằng chứng “tương thích Word”.
- Cloud library: không triển khai; cần quyết định backend/bucket/quota/RLS và
  quyền chia sẻ trước khi mở rộng.

## Migration, rollback và khôi phục

1. Document store v2 là migration additive từ guest localStorage; dữ liệu cũ
   không bị xóa, lỗi quota vẫn có fallback cũ để retry.
2. Draft store là DB riêng v1; owner/document ID/base revision cô lập. Draft
   stale chỉ đưa ra lựa chọn, không tự merge.
3. `GUIDE_CONTENT_VERSION` chuyển namespace sang `v5.10`; reset guide không xóa
   project/document.
4. Bản gốc DOCX luôn giữ bytes; Lưu/Xuất tạo bản mới. Rollback code về v5.9
   không chạy migration destructive; giữ DB để bản mới có thể đọc lại.

## Hướng dẫn dùng

1. **Upload thư viện:** Quản lý thư mục → Tài liệu đã tải lên → Tải tài liệu lên;
   chọn PDF/DOCX/PPTX/XLSX, tìm/lọc, mở viewer, tải bản gốc hoặc xóa record.
2. **Chèn canvas:** Trong canvas mở panel tài liệu, tìm file và chọn Import;
   node lưu reference dùng chung, xóa node không xóa file thư viện.
3. **PDF editor:** Trung tâm học tập → Công cụ → Vẽ trên PDF → chọn PDF; dùng
   pen/highlight/eraser realtime, Ctrl+Z/Y, Space pan, Ctrl-wheel hoặc Ctrl+
   kéo để zoom, Xuất PDF tạo bản mới. Embedded viewer vẫn theo quy tắc fullscreen.
4. **DOCX editor:** Công cụ → Soạn thảo DOCX → chọn DOCX hoặc Tạo DOCX mới;
   sửa trong giấy, chọn vùng rồi dùng ribbon, chỉnh bảng/ảnh/header/footer,
   Ctrl+S hoặc Lưu bản sao, sau đó Xuất DOCX. Nguồn nhập không bị ghi đè.
