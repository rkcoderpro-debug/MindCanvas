Không cần migration SQL để xử lý các lỗi build TypeScript này. Không chạy `npm audit fix --force` trong bản sửa này vì cảnh báo audit không chặn build và lệnh đó có thể nâng phiên bản phá vỡ tương thích.

## Cách áp dụng và deploy

1. Giải nén gói từ thư mục cha chứa repository `mindcanvas-v1` để các đường dẫn `mindcanvas-v1/...` trong ZIP phủ lên đúng file hiện có. Không giải nén bên trong repository vì sẽ tạo thêm một thư mục con cùng tên.
2. Xác nhận hai file trên tồn tại trong `apps/web/src/lib/`.
3. Chạy `npm install` rồi `npm run build --workspace apps/web`.
4. Commit các thay đổi lên đúng nhánh GitHub đang nối với Render, sau đó push để Auto-Deploy chạy lại.
5. Chờ Render báo deploy thành công; kiểm tra log không còn lỗi `quizReveal*` hoặc `flashcardStorage`, rồi tải lại web để xác nhận badge V5.13.0.
