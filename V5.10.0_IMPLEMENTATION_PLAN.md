# MindCanvas v5.10.0 — kế hoạch triển khai và cổng nghiệm thu

Tài liệu này khóa phạm vi triển khai DOCX Editor thực dụng cho học tập/văn
phòng. Mammoth chỉ được giữ ở viewer DOCX của thư viện; editor dùng document
model có cấu trúc và writer OOXML riêng. Không tuyên bố tương đương toàn bộ
Microsoft Word.

## A — Audit và tái hiện

- Đọc routing, `documentStore`, `FolderManager`, `DocumentViewer`,
  `DocumentToolsPage`, `CanvasBoard`, Learning Hub, Feature Guide và shortcut.
- Kiểm tra worktree bẩn, giữ nguyên các thay đổi v5.9 và các bản trước.
- Tái hiện DOCX đứng trước PDF trong danh sách; guide PDF phải không nhận event
  của DOCX. Regression nằm trong `DocumentToolsPage.test.tsx` và
  `FeatureGuideOverlay.test.tsx`.
- Ghi nhận lỗi UI cũ: vùng HTML dài không có paper model, warning kỹ thuật
  Mammoth, banner nháp lớn và toolbar thiếu ngữ cảnh.

## B — Compatibility spike

- Kiểm tra Mammoth `1.12.3` (BSD-2-Clause): chỉ chuyển DOCX → HTML, không phải
  editor round-trip. Vì vậy nó không được dùng làm nguồn dữ liệu duy nhất.
- Giữ JSZip `3.10.2` để đọc/ghi package OOXML ngay trên thiết bị; không thêm
  backend, dịch vụ trả phí, credential hay public upload.
- Fixture model được chứng minh theo chu trình DOCX/OOXML → import → sửa model →
  export → mở lại trong parser; output writer được LibreOffice mở và render PDF.
- Các phần cần Word/Office thật, browser E2E và ảnh screenshot vẫn là cổng
  môi trường riêng, không được suy diễn từ unit test.

## C — Model, OOXML và draft/revision

- `docxModel.ts` định nghĩa paragraph/run/style/list/table/image/page-break,
  page settings, header/footer, relationships, media và warning tương thích.
- Import đọc `document.xml`, `styles.xml`, `numbering.xml`, relationships,
  media, section settings, header/footer; Title/Subtitle/Heading được map có
  chủ đích.
- Export tạo package hợp lệ với styles, numbering, hyperlinks, media,
  header/footer, PAGE field, section/page settings; không đổi HTML thành đuôi
  DOCX.
- `docxDraftStore.ts` dùng IndexedDB theo owner + document ID + base revision.
  Draft stale không tự merge; người dùng chọn khôi phục hoặc mở bản hiện tại.
  Nguồn nhập luôn giữ bytes và lần Lưu đầu tạo bản sửa riêng.

## D — Editor và ribbon

- `DocxEditor.tsx` dùng DOM làm editing surface nhưng model là nguồn lưu/export.
- Có topbar trạng thái, rename, undo/redo, Lưu, Lưu bản sao, Xuất DOCX,
  fullscreen; ribbon Trang đầu/Chèn/Bố cục/Xem và status bar.
- Đã triển khai style/heading, font/cỡ, mark, màu/highlight, align/list/indent,
  find/replace, copy/clear format, symbol, link, page break, A4/Letter,
  orientation/lề/thước/continuous/zoom.
- Context tool cho bảng (hàng/cột, gộp/tách trong phạm vi cùng hàng, header,
  nền/căn, xóa có xác nhận) và ảnh (resize giữ tỷ lệ, alt, thay/xóa/căn).
- Header/footer là vùng sửa được; footer export thêm PAGE field. Shortcut trong
  editor không cướp P/E/H/V/Space của canvas và Ctrl/Cmd+B/I/U/Z/Y/S/F.

## E — Library, tools và guide

- `DocumentToolsPage` dùng chung repository local, cho chọn PDF/DOCX, tạo DOCX
  trắng, quay về Công cụ; `DocumentViewer` giữ PDF guide typed theo kind/id/
  viewer session.
- Guide DOCX kiểm chứng event thật: open/focus, text, selection, format, table,
  save và export; event gắn document ID/session ID. Guide PDF không tiến vì
  selector dòng đầu hoặc event DOCX.
- Overlay cleanup timer/listener/route; spotlight sáng toàn target, popover tránh
  vùng thao tác. Nút `?` chỉ xuất hiện sau guide tương ứng hoàn thành.

## F — Verification và bàn giao

- Gate bắt buộc: `npm test`, `npm run typecheck`, `npm run build`, targeted DOCX
  regression và server health smoke.
- Fixture writer được mở bằng LibreOffice headless và render PDF; browser thật,
  Word desktop và screenshot UI phải chạy trên môi trường có browser/Office.
- ZIP chỉ chứa file thay đổi với prefix `mindcanvas-v1/`; không gồm
  `node_modules`, `dist`, cache, `.env`, secrets hay file fixture riêng tư.
- Không đóng release production khi blocker phân trang thật, OOXML nâng cao,
  browser E2E hoặc Word round-trip chưa có bằng chứng.

## Rủi ro đã khóa

1. Phân trang hiện là paper surface + page-count đo theo chiều cao; chưa có
   layout engine phân trang thật giữ caret/selection/IME qua nhiều page.
2. RowSpan arbitrary, floating/wrap image, tracked changes/comments/fields,
   OMML và style tùy biến phức tạp chưa phải round-trip đầy đủ; import cảnh báo
   và bảo toàn bản gốc.
3. Browser E2E không chạy được nếu runtime không có Chrome/Firefox; Word
   desktop cũng không có trong container.
4. Repository là local-only. Multi-device/cloud cần quyết định backend, bucket,
   quota/RLS và quyền mới; không tự triển khai.
