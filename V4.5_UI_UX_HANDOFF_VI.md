# MindCanvas V4.5 — UI, UX và cộng tác

V4.5 giữ nguyên dữ liệu, quyền truy cập và migration V4.4. Bản này tập trung vào app shell gọn hơn, lazy-load các màn hình nặng, Focus mode, motion/theme token, responsive mobile và presence nhẹ cho người đang mở cùng project.

## Điểm mới

- Entry bundle được tách route; Canvas, Learning Hub, Share, Admin và các dialog nặng tải khi cần.
- Focus mode ẩn navigation, giữ canvas ở trung tâm và lưu lựa chọn trên thiết bị.
- Phím tắt `Ctrl/⌘ + Shift + F` bật/tắt Focus mode; `Ctrl/⌘ + K` vẫn mở Quick actions.
- Hiển thị số người đang online trong project khi Supabase Realtime hoạt động.
- Thêm motion token, touch target và reduced-motion support cho nền giao diện.
- Release health đổi thành `4.5.0`; service-worker cache đổi sang `mindcanvas-shell-v4.5-calm-collab`.

## Cài vào repo hiện tại

1. Tải ZIP V4.5, giải nén vào thư mục repo MindCanvas và giữ nguyên cấu trúc thư mục.
2. Chọn ghi đè file khi Windows hỏi.
3. Không ghi đè các file `.env`.
4. Mở PowerShell hoặc Git Bash tại thư mục repo.

## Kiểm tra trước khi commit

```bash
git status
npm install
npm run typecheck
npm test
npm run build
git diff --check
```

Không cần chạy `npm audit fix --force`; cảnh báo audit không liên quan đến lỗi TypeScript và lệnh force có thể tạo breaking changes.

## Commit và push lên GitHub

Git tự tạo mã commit. Không cần nhập hoặc tự tạo mã đó.

```bash
git status
git add -A
git diff --cached --stat
git commit -m "feat: MindCanvas V4.5 UI UX and collaboration polish"
git pull --rebase origin main
git push origin HEAD:main
```

`git push origin HEAD:main` đẩy đúng commit của branch hiện tại lên `main`, kể cả khi branch local đang tên `repair/...`. Không dùng `git push --force`.

Nếu `git pull --rebase` báo conflict, dừng lại và xử lý từng file:

```bash
git status
# sửa các file được báo conflict
git add <file-da-sua>
git rebase --continue
git push origin HEAD:main
```

## Render

Sau khi GitHub nhận commit, vào Render → service web → **Manual Deploy** → **Deploy latest commit** nếu Render chưa tự chạy.

Giữ build command:

```bash
npm install && npm run build --workspace apps/web
```

Không có migration Supabase mới cho V4.5. Migration `0011_v4_4_collaboration.sql` của V4.4 vẫn phải tồn tại và đã được chạy trước đó.

## Kiểm tra sau deploy

1. Mở trang ở desktop và mobile 390px.
2. Bật/tắt Focus mode và tải lại trang để kiểm tra việc ghi nhớ.
3. Mở một project cloud; kiểm tra entry app không còn tải toàn bộ Learning Hub/Share ngay từ đầu.
4. Mở cùng project bằng hai tài khoản đã được cấp quyền; kiểm tra avatar/số người online.
5. Kiểm tra editor vẫn sửa được, viewer vẫn chỉ pan/zoom.
6. Kiểm tra theme, `prefers-reduced-motion`, offline status và nút retry.
