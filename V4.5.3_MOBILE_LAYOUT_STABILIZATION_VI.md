# MindCanvas V4.5.3 — Mobile Layout Stabilization

Bản này xử lý trực tiếp các lỗi được phát hiện từ ảnh chụp thiết bị thật sau V4.5.2, tập trung vào Canvas mobile, horizontal overflow, header editor, cụm điều khiển đáy và fullscreen.

## 1. Canvas mobile header riêng

- Ẩn desktop topbar khi đang mở Canvas trên màn hình <= 620px.
- Thêm header mobile chỉ gồm:
  - quay lại Workspace;
  - tên project có ellipsis;
  - trạng thái lưu dạng icon;
  - nút `...` mở menu project.
- Các thao tác Undo, Redo, Version History, Move, Share, Export JSON/SVG/PNG và AI được đưa vào bottom sheet thay vì nhét trên một hàng ngang.
- Bottom sheet hỗ trợ đổi tên project và đóng bằng Escape/click backdrop.

## 2. Loại bỏ horizontal page overflow

- `html`, `body`, `#root` được giới hạn `width/max-width: 100%` và chặn overflow ngang ở cấp root.
- `main-area`, `editor-layout`, `editor-frame`, Learning Hub và Workspace được ép `min-width: 0`/`max-width: 100%` trên mobile.
- Khi Canvas mở, desktop editor heading và hàng action dài bị ẩn hoàn toàn trên mobile.

## 3. Mobile Canvas Dock thống nhất

- Gom `Thuộc tính` và `CanvasNavigator` vào một dock duy nhất ở đáy Canvas.
- `Đến phần đã chọn` chỉ được render khi thực sự có selection.
- Nút minimap được ẩn trên mobile để giảm chiều ngang.
- Zoom nằm tách phía trên dock.
- Toolbar collapsed nằm cùng tầng điều khiển nhưng không còn chen vào navigator/properties.

## 4. Fullscreen mobile

- Khi fullscreen:
  - ẩn mobile Canvas header;
  - ẩn global bottom navigation;
  - Canvas chiếm 100dvh;
  - bỏ margin/border radius của editor.
- Trên màn hình <= 620px, app thử gọi Fullscreen API của trình duyệt; nếu trình duyệt không cho phép thì vẫn dùng app-level fullscreen làm fallback.
- Khi thoát fullscreen bằng UI hệ thống, state trong app được đồng bộ lại qua `fullscreenchange`.

## 5. Learning Hub navigation

- Tab bar giữ label, cuộn ngang bằng touch và dùng scroll snap.
- Không còn thiết kế kiểu một vài tab có chữ còn tab cuối chỉ còn icon.

## 6. Màn hình rất nhỏ

- <= 420px vẫn giữ bottom navigation 4 mục.
- Canvas main area chừa đúng khoảng cho bottom navigation.
- <= 340px tự rút gọn nhãn Properties và tên tool để tránh tràn ngang.

## Kiểm tra đã chạy

PASS:

```bash
npm run typecheck
npm run build --workspace apps/server
git diff --check -- apps/web/src/App.tsx apps/web/src/components/AppSidebar.tsx apps/web/src/components/CanvasBoard.tsx apps/web/src/components/CanvasNavigator.tsx apps/web/src/styles.css
```

Frontend Vitest/Vite build chưa thể khởi động trong workspace Linux hiện tại vì `node_modules` trong ZIP được cài trên Windows, nên thiếu native package Linux `@rollup/rollup-linux-x64-gnu`. Đây là lỗi môi trường trước bước chạy source.

Trên máy phát triển đúng nền tảng, chạy lại:

```bash
npm ci
npm run test
npm run build
```

11. Learning Hub: swipe tab ngang, mọi tab vẫn có label.
12. Xoay dọc/ngang và kiểm tra safe-area.
