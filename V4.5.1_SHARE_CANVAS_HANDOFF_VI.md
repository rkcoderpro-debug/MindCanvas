# MindCanvas V4.5.1 — hướng dẫn cài, migration và push

Bản vá này sửa Share page, lỗi RPC Supabase `PGRST202`, Alt + wheel ngang và bố cục canvas trên điện thoại. Dữ liệu V4.4, quyền owner/editor/viewer và luồng fullscreen/pinch/pan được giữ nguyên.

## 1. Chép bản vá vào repo Windows

Giải nén ZIP vào đúng thư mục repo, ví dụ:

```text
C:\Users\VTIEN\Downloads\Compressed\mindcanvas-v1
```

Chọn ghi đè khi Windows hỏi, nhưng không ghi đè `.env`, `.env.local` hoặc thông tin đăng nhập. Giữ nguyên cấu trúc `apps/`, `packages/` và `supabase/`.

Mở PowerShell tại thư mục đó:

```powershell
cd C:\Users\VTIEN\Downloads\Compressed\mindcanvas-v1
git status
npm install
npm run typecheck
npm test
npm run build
git diff --check
```

Không cần chạy `npm audit fix --force`; cảnh báo audit không sửa được lỗi RPC và có thể gây breaking changes.

## 2. Sửa Supabase (bắt buộc cho tính năng Share)

Trong Supabase Dashboard → **SQL Editor**:

1. Mở và chạy toàn bộ `supabase/migrations/0011_v4_4_collaboration.sql` nếu các bảng V4.4 chưa tồn tại.
2. Mở và chạy toàn bộ `supabase/migrations/0012_v4_5_1_share_rpc_repair.sql`.
3. Chờ vài giây rồi tải lại app. Migration 0012 đã gửi `NOTIFY pgrst, 'reload schema'`.

Kiểm tra nhanh trong SQL Editor:

```sql
select
  to_regprocedure('public.create_project_invitation(uuid,text,text,text,timestamptz)'),
  to_regprocedure('public.list_project_members(uuid)'),
  to_regprocedure('public.list_project_invitations(uuid)');
```

Ba cột phải trả về tên function, không được là `null`. Nếu vẫn thấy `PGRST202`, chạy lại migration 0012 trên đúng project Supabase mà Render đang dùng và kiểm tra biến `VITE_SUPABASE_URL`/`SUPABASE_URL`.

Nếu dùng Supabase CLI thay cho Dashboard:

```powershell
npx supabase login
npx supabase link --project-ref <project-ref>
npx supabase db push
```

## 3. Commit và push lên GitHub

Git tự tạo mã commit; không cần nhập mã đó. Đẩy đúng branch hiện tại lên `main` bằng `HEAD`:

```powershell
git add -A
git diff --cached --stat
git commit -m "fix: MindCanvas V4.5.1 sharing and mobile canvas"
git pull --rebase origin main
git push origin HEAD:main
```

`git push origin HEAD:main` hoạt động cả khi branch local tên `repair/...`. Không dùng `git push --force`.

Nếu rebase báo conflict:

```powershell
git status
# sửa các file được báo conflict
git add <file-da-sua>
git rebase --continue
git push origin HEAD:main
```

Nếu GitHub yêu cầu đăng nhập, dùng GitHub Desktop hoặc Personal Access Token (GitHub không nhận mật khẩu tài khoản cho HTTPS push).

## 4. Render và kiểm tra thực tế

- Render → service web → **Manual Deploy** → **Deploy latest commit** nếu chưa tự deploy.
- Build command giữ nguyên: `npm install && npm run build --workspace apps/web`.
- Mở Share từ project owner: trang phải nằm trong vùng làm việc, không xuất hiện thanh kéo ngang.
- Tạo lời mời, đổi role, thu hồi lời mời; lỗi RPC phải hiện hướng dẫn migration thay vì JSON `PGRST202`.
- Trên canvas: wheel thường cuộn dọc; giữ `Alt` + wheel cuộn ngang; `Ctrl`/pinch vẫn zoom.
- Kiểm tra 390px trên Chrome/Brave mobile: toolbar không đè lên zoom/navigator/Properties; mở Properties vẫn là bottom sheet.
