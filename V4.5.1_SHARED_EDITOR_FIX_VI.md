Không cần migration mới. Giữ bản sửa SELECT policy đã chạy ở lượt trước;
không chạy lại migration 0013 cũ vì sẽ phục hồi policy SELECT lỗi.

## Cài và push

Xuất JSON các canvas chưa lưu trên từng thiết bị trước khi cập nhật.
Mở terminal tại repo:

```powershell
npm run test --workspace apps/web
npm run build --workspace apps/web
git add apps/web/public/sw.js apps/web/src/hooks/useWorkspace.ts apps/web/src/hooks/useWorkspace.test.tsx apps/web/src/lib/projectStore.ts apps/web/src/lib/sharedPersistence.test.ts V4.5.1_SHARED_EDITOR_FIX_VI.md
git diff --cached --stat
git commit -m "fix: preserve shared canvas revision and editor saves"
git pull --rebase origin main
git push origin HEAD:main
```

Nếu rebase có conflict, dừng để giải quyết; không force push.
Render deploy commit mới. Cả owner và editor tải lại app online,
bấm Update now nếu có. Không xóa localStorage/IndexedDB.

## Khôi phục bản nháp và kiểm tra

- Mở canvas được chia sẻ, bấm Thử lại.
- Nếu nội dung local khác cloud và thiếu revision, app hiển thị xử lý xung đột.
  Chọn lưu thành bản sao để giữ bản nháp mà không đè lên canvas chung.
  Chỉ chọn ghi đè khi đã đối chiếu nội dung và muốn thay thế bản cloud.
- Editor mở lại canvas từ danh sách, sửa nội dung, chờ Đã lưu rồi tải lại.
- Owner kiểm tra nội dung mới; thử hai thiết bị sửa cùng lúc để xác nhận
  xung đột được báo thay vì tự ghi đè.
- Viewer vẫn không được sửa.

Thay đổi: giữ snapshot đầy đủ khi mở project; UPDATE có điều kiện revision;
không INSERT bản nháp chia sẻ thiếu revision; duplicate ID chuyển sang
luồng xử lý xung đột; cache service worker mới.
Chưa kiểm thử trực tiếp database production hoặc hai tài khoản thật.
